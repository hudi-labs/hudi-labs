# BrandbookManual

Compõe o Brand Book como uma página própria e estática, usando a mesma base visual e navegação da landing page.

```tsx
<BrandbookManual />
```

Não recebe propriedades. As cinco seções refletem o sistema da marca: propósito, voz, identidade, paleta e UI. Mantenha os identificadores das seções para que a navegação interna continue acessível.
