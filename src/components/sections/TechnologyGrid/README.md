# TechnologyGrid

Exibe as capacidades de conectividade da Hudi Labs como uma grade acessível e responsiva.

```tsx
<TechnologyGrid />
```

Não recebe propriedades. O conteúdo vem da coleção `capabilities` em `src/data/site-content.ts`; cada item exige `name`, `description` e um ícone suportado pelo mapa interno.
