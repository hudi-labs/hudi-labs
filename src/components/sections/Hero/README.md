# Hero

Seção inicial da landing page. Comunica o posicionamento da Hudi Labs, oferece os dois caminhos de conversão prioritários e reage ao cursor com luz e parallax sutil do ecossistema em dispositivos de ponteiro preciso.

```tsx
<Hero />
```

Não recebe propriedades. A interação é desativada para touch e respeita `prefers-reduced-motion`. A copy é deliberadamente institucional; alterações de posicionamento devem passar pela revisão do Brand Book antes de serem aplicadas aqui.
