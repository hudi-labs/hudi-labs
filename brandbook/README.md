# Brand Book Hudi Labs

O Brand Book canônico é implementado como rota estática da aplicação em [`src/app/brandbook/page.tsx`](../src/app/brandbook/page.tsx), com conteúdo no componente [`BrandbookManual`](../src/components/brandbook/BrandbookManual/README.md).

Após o deploy no GitHub Pages, ele fica disponível em `/brandbook/` e mantém navegação bidirecional com a landing page principal.

Este diretório deixou de hospedar um HTML paralelo para evitar duas versões divergentes do manual de marca.
